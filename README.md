#🎮 Brick Breaker Game

A retro-inspired **Brick Breaker game** built using HTML, CSS, and JavaScript. The game features a neon-themed interface, glowing bricks, particle effects, and multiple levels for an engaging arcade experience.

## 🚀 Features

* 🎨 **Neon UI:** Futuristic interface with glowing cyan, pink, yellow, and green effects.
* 🕹️ **Interactive Gameplay:** Control the paddle using your mouse or keyboard arrow keys.
* 🧱 **Brick Collision:** Break bricks by bouncing the ball off the paddle.
* 💯 **Score Tracking:** Earn points for every brick destroyed.
* ❤️ **Lives System:** Start with three lives.
* 📈 **Multiple Levels:** Advance to the next level after clearing all the bricks.
* ⚡ **Increasing Difficulty:** The ball gets faster as you progress through levels.
* ✨ **Particle Effects:** Visual effects appear when the ball hits bricks.
* 🏆 **Best Score:** Displays the highest score achieved during the current session.
* 🌌 **Retro Visual Effects:** Includes a grid background, scanlines, and glowing elements.

## 🛠️ Technologies Used

* **HTML5** – Structures the game interface.
* **CSS3** – Creates the neon theme, animations, and visual effects.
* **JavaScript** – Implements game logic, ball movement, collision detection, scoring, and level progression.
* **HTML5 Canvas API** – Renders the ball, paddle, bricks, and particle effects.

## 🎯 How to Play

1. Open the game in your web browser.
2. Click **START GAME** to begin.
3. Move your mouse to control the paddle.
4. Click the game area or press **Spacebar** to launch the ball.
5. Bounce the ball off the paddle to hit and destroy the bricks.
6. Avoid letting the ball fall below the paddle.
7. Clear all the bricks to advance to the next level.
8. Try to achieve the highest possible score!

### 🎮 Controls

| Action               | Control                        |
| -------------------- | ------------------------------ |
| Move paddle left     | Left Arrow Key or Mouse        |
| Move paddle right    | Right Arrow Key or Mouse       |

| Start / Restart game | Start Game / Play Again button |

## 💻 How to Run the Project

No additional software installation is required.

1. Download or clone this repository.
2. Locate the HTML file containing the game code.
3. Open the file in a modern web browser, such as Chrome, Edge, or Firefox.
4. Click **START GAME** and enjoy playing!

Alternatively, open the project in Visual Studio Code and run the HTML file using the Live Server extension.
